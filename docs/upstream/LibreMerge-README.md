# LibreMerge documentation reference

MergeDesk adopts LibreMerge source at commit
`cb7d5ba48c552cb4643ab8247f4cc692df8f3261`. The original project's usage and
build documentation is available in its
[pinned upstream README](https://github.com/iagodpassos/libremerge/blob/cb7d5ba48c552cb4643ab8247f4cc692df8f3261/README.md).

For MergeDesk's supported platforms, features and build commands, use the
[MergeDesk README](../../README.md), [manual](../MANUAL.md) and
[build guide](../BUILDING.md).

The retained [upstream author acknowledgments](LibreMerge-CONTRIBUTORS.md)
and [vendoring record](LibreMerge-VENDORED.md) identify the reused work.
[THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md) contains the notices also
available from MergeDesk's About dialog. Original copyright and license
notices remain in force.
