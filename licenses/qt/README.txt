MergeDesk dynamically links Qt. The application is GPL-3.0-or-later.
Qt modules are distributed under their applicable GPL/LGPL terms, with the
complete license texts included here. The distribution's Qt copyright notices
and the WebEngine/Chromium third-party component notices are also included in
each binary package. Libraries remain separate, replaceable shared libraries.

Qt source archives corresponding to official binary versions:
https://download.qt.io/archive/qt/
Release packages use the reviewed version in packaging/qt-runtime.json.
The versioned source-archives.json records the corresponding Qt source and
its published SHA-256 checksum. SDK dependencies such as ICU have separate
source and license records in the same versioned directory.

Windows and GNU/Linux packages contain full component notices collected from the
official documentation for the exact Qt patch release, with source URLs and
SHA-256 checksums for the original pages. The inventory includes all Qt modules
and platforms; BUILD-METADATA.json identifies the actual deployed libraries.

GNU/Linux packages also contain the complete Debian copyright and license
manifests for their bundled system libraries, plus the full common license
texts those manifests reference. Their exact binary and source package
versions are recorded in licenses/system-packages/metadata.json; corresponding
source archive records are obtained from the signed APT source indexes.
